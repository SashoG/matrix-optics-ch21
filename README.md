# Матрични методи в оптиката — код към Глава 21

Придружаващ код към Глава 21 „Автоматизация на матричните пресмятания“ от
учебника

> Александър Гайдарджиев, *Матрични методи в оптиката. Част I: Геометрична оптика*,
> Софийски университет „Св. Климент Охридски“.

*English summary: companion Python code for Chapter 21 of a Bulgarian textbook
on matrix (ABCD) optics. `mathOptics.py` contains the chapter's listings verbatim
and reproduces every number printed in the chapter; `exercises_ch21.py` solves
problems 21.1–21.6 and checks the results against the book.*

## Файлове

| Файл | Съдържание |
|---|---|
| `mathOptics.py` | Кодът от Листинги 21.1–21.8 **дума по дума** и скрипт, който възпроизвежда таблици 21.2–21.3, фиг. 21.3 и числата от §21.7 |
| `exercises_ch21.py` | Решения на задачи 21.1–21.6; всяко число се сравнява с отпечатаното в книгата |

### Листинг → код

| Листинг | В `mathOptics.py` |
|---|---|
| 21.1 Базовите матрици | `S`, `R`, `L` |
| 21.2 Сглобяване на системата | `system_matrix`, `check_unimodular` |
| 21.3 Кардинални елементи | `cardinal` |
| 21.4 Триплетът от таблица 21.1 | скриптът, раздел „Таблица 21.2“ |
| 21.5 Таблица на чувствителността | скриптът, раздел „Таблица 21.3“ |
| 21.6 Монте Карло | скриптът, раздел „Фигура 21.3“ |
| 21.7 Секущ метод | `f_of_t4`, `secant` в скрипта |
| 21.8 Автоматични тестове | `test_thin_lens`, `test_thick_lens_example`, `test_afocal_raises` |

Разделът „§21.7 (продължение)“ в края на скрипта е **извън листингите**: той
пресмята стъпките на секущия метод, сравнението с бисекцията и компенсатора
(поправката на $t_4$ за всеки от 20 000-те екземпляра).

## Изисквания и стартиране

Python ≥ 3.6, NumPy ≥ 1.17; SciPy е по желание (само за `brentq`).

```bash
pip install -r requirements.txt
python mathOptics.py          # всички числа от главата (~10 s)
python exercises_ch21.py      # задачите, с проверка срещу книгата
python -m pytest mathOptics.py   # само трите теста от Листинг 21.8
```

## Конвенции

Същите като в книгата: лъчев вектор $(y, V)$ с $V = n\theta$; преместване
$\hat S(T)$ с приведена дебелина $T = t/n$; пречупване $\hat{\mathfrak R}(P)$ с
$P = (n' - n)/r$; в произведението последният елемент стои най-отляво. Всички
дължини са в милиметри. Плоска повърхност се задава с `r = np.inf`.

## Възпроизводимост

Методът Монте Карло ползва `np.random.default_rng(2026)`. Числата в книгата са
проверени с Python 3.13, NumPy 2.5 и SciPy 1.18. NumPy не гарантира еднакъв
поток от случайни числа между всички свои версии; ако на друга версия третият
знак след запетаята се различава, причината е в генератора, а не в оптиката.
